## 建议的补法（两件，都在新骨架上）

1. **浏览器路径栏加一个「导入」按钮**（`Controls/AssetBrowser.xaml` 的路径栏现在有
   返回 / 上一层 / 当前路径 / 打开目录，再加一个），按 `_currentAssetCategoryKey` 分发：
   - 背景图 → 选择器 + `ImportBackgroundImagesAsync`
   - 道具图片 → 选择器 + `ImportPropImagesAsync`
   - 音乐 / 环境音 / 特殊音效 → 一个通用选择器 + `ImportAudioFiles(kind, …)`
   - 函数 / 角色滤镜 / 立绘 → 各自另有入口（函数是"新建函数"卡；滤镜是"新建滤镜"卡；
     立绘在角色详情页里导入图层）
2. **浏览器网格接受文件拖入**：`AssetBrowserHost.CardsHost` 设 `AllowDrop`，
   挂 `DragOver` / `Drop`，同样按当前分类分发 → 保住"拖入即导入"的手感。

分发可以复用现成的 `_currentAssetCategoryKey` 与 `RefreshCurrentAssetCategoryAsync`
（导入完重铺当前分类 ✓）—— 与"改备注 / 替换 / 删除"那 12 处是同一套机制。
