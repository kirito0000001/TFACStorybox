# 顶部轻提示组件 TipToast（2026-11-04）

> 需求：把 AX 工具箱那个「顶部居中、带圆角与动画的 Tips」搬到剧情工具箱，
> 普通白字 / 警告黄字 / 报错红字；原样式不再用，但**剧情编辑器里那个持久提示保留**。
> 追加要求：做成「一个地方改好，拷到别的项目也能用」的东西。

## 1. 为什么不用 UserControl

WinUI 里正统做法是 `UserControl`（.xaml + .xaml.cs + x:Class）。但它不适合「跨项目复制」：

| 复制用户控件要改 | 说明 |
|---|---|
| 命名空间 | `.xaml` 的 `x:Class`、`.xaml.cs` 的 namespace 必须一致 |
| 工程文件 | 新项目要加 `<Page Include>`，漏了就运行期找不到 |
| 资源字典 | 控件里引用的 `ThemeResource` 在别的项目可能不存在，轻则样式丢、重则崩 |
| 主题 | 两套主题各写一份颜色，搬过去还得对齐 |

所以这里选**单文件、纯代码搭视觉树、零 ThemeResource**：
拷 `Controls/TipToast.cs` 一个文件、改掉 namespace 就能跑，长相不随目标项目的资源漂移。

## 2. API

```csharp
TipToast.Attach(RootGrid);                       // 窗口根 Grid，构造里调一次
TipToast.Show(TipToastSeverity.Warning, "标题");
TipToast.Show(TipToastSeverity.Error, "失败", ex.Message);
TipToast.Show(TipToastSeverity.Info, "已复制", null, TimeSpan.FromSeconds(1.4));
TipToast.Clear();                                // 立即清空
```

- `Show` 可以从**任意线程**调（内部 `DispatcherQueue` 兜住）。
- `Attach` 幂等；没 Attach 时 `Show` 静默返回，不抛。
- 同屏最多 2 条，超出时**优先挤掉非报错**里最旧的那条 —— 报错往往才是要看的那条。

## 3. 外观

| 等级 | 标题颜色 |
|---|---|
| Info / Success | 白 `#FFFFFFFF` |
| Warning | 黄 `#FFFFD166` |
| Error | 红 `#FFFF7B7B` |

- 背景统一 `#E61F1F1F`（深色半透明）+ 1px 白 15% 描边 + `CornerRadius 8`。
  深浅主题都不用另配一套 —— 深色块在浅色页面上照样读得清。
- 位置：**内容区**顶部居中（挂 `RootGrid` 第 1 行，不压 48px 的标题栏），距顶 18px；
  `Canvas.ZIndex = 9000`；容器 `IsHitTestVisible=false`（提示只用来"看"，不该挡住下面的按钮）。
- 动画：**200ms 淡入 + 0.94→1 的轻微放大，没有位移**（`CubicEase EaseOut`，
  放大原点在正上方，像"从顶上浮现"）；退场 120ms 淡出后摘除。
  > 2026-11-04 改过一版：最初我自作主张加了「从上滑下 10px」，用户指出 AX 那个提示没有位移。
  > AX 用的是 WinUI `TeachingTip`（`MainWindow.Log.cs:110-124`，只设 Title + IsOpen），
  > 它的默认入场就是淡入 + 轻微放大，所以位移去掉了。
- 停留：普通 2.6s / 警告 3.2s / 报错 5s（沿用原有时长）。
- **兜底**：先把 `Opacity` 落成 1 再起动画。万一 Storyboard 没跑起来，提示至少看得见，
  不会留下一个隐形块；退场动画失败则直接摘除，避免永久挂着。

## 4. 与旧实现的关系

| 位置 | 处理 |
|---|---|
| `MainWindow.Tips.cs` 无 panel 的 `ShowFloatingTip` | **改走 `TipToast`**。它是 114 个调用点的唯一出口，签名没变，调用点一行没动 |
| `MainWindow.Tips.cs` 带 panel 的重载 | **保留**，仍是 InfoBar —— 剧情编辑器的持久条靠它 |
| `MainWindow.xaml` `FloatingTipsPanel` | 删除（原来右上角的 InfoBar 堆栈） |
| `StoryFloatingTipsPanel` | **不动**（持久显示，靠 `PersistentStoryStatusTag` 参与 Trim） |
| 日志与错误复制 | 抽成 `RecordFloatingTip`，两条路径共用，避免"换了样式却没记日志" |

## 5. 跨项目复用的两种方式

1. **复制**：把 `Controls/TipToast.cs` 拷过去，改 namespace。（零依赖，最省事）
2. **共享源文件**（推荐，真正"一处改两处生效"）：两个项目都不放副本，各自 csproj 里引同一个文件：

```xml
<ItemGroup>
  <Compile Include="..\Shared\TipToast.cs" Link="Controls\TipToast.cs" />
</ItemGroup>
```

改那一个文件，两边同时生效；不需要发包、不需要类库版本管理。
（如果要给第三方用，再考虑抽成 `TipToast.dll`。）
