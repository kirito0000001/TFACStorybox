# 项目分区会话返回设计

## 目标

用户从“项目工作台”分区切到素材库补充素材后，再次进入项目分区时，回到离开前的稳定页面。剧情编辑器需要保留当前章节、当前句、侧栏状态和撤回栈，并在返回时重新读取关联素材库。

## 范围

- 记录项目列表、项目详情、剧情编辑器和项目文本工具四种稳定页面。
- 离开剧情编辑器前立即保存当前句、章节位置并等待保存队列完成。
- 返回剧情编辑器时复用内存中的 StoryDocument，不重新打开章节；重新解析项目关联素材库并刷新当前句预览。
- 素材库、虚幻同步台和设置页不记录内部页面，进入时仍显示各自默认首页。
- 创建项目等临时页面不作为返回目标。

## 失败回退

若项目、章节或剧情文档在外部被删除，无法恢复剧情编辑器时回到项目列表，避免显示失效状态。

## 验证

- 静态回归脚本检查保存顺序、恢复路径和素材库默认入口。
- Debug 构建必须为 0 警告、0 错误。
- 运行现有剧情编辑器、函数、素材传播及源码健康回归脚本。
