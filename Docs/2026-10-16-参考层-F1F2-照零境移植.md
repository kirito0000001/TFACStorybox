# 参考层（F1 / F2）—— 照隔壁零境工具箱移植

2026-10-16 移植。**来源**：`D:\UnrealMap\CrossingVoidZDTool`（零境工具箱）的 F1–F4 那一套。

## 零境那边原本是什么

它是一整套「**文本参考浮层**」，共用一个层（那边的 `DraftOverlayHost`）：

| 键 | 内容 |
|---|---|
| F1 | **上下文帮助**：在设置页给「设置页 Tips 合集」，其它页给「快捷键大全 + 各页（St1–St5）说明」 |
| F2 | **当前角色草稿本**：读那个角色目录里的设计草稿文本；没选中角色就提示一句 |
| F3 | 技能数值倍率规范（写死的规范文本） |
| F4 | 当前页面填写法则 |
| Esc | 关掉最上面那层；右键也能关 |

两个关键做法（比"内容"更值得抄的是这两条）：

1. **加速器挂在根元素上**（`RootGrid.KeyboardAccelerators` + `ScopeOwner = RootGrid`）——
   所以**任何页面**都按得动。挂在某个页面上，离开那页就失效。
2. **一层多用**：四个键只是往同一个层里塞不同的标题与文本，层本身只管显隐与关闭。

## 这边怎么适配

对象从"角色"换成"**章节**"（这个工具里"正在编辑的东西"就是章节）：

| 键 | 内容 | 实现 |
|---|---|---|
| F1 | 设置页 → 设置 Tips 合集；其它页 → 快捷键大全（全局 + 剧情编辑器那套 + 各区域一句话） | `ShowShortcutGuideOverlay()` |
| F2 | **当前章节参考**：概览（名/代号/句数/小节数/备注数）+ 小节结构（每节从第几句起、首句预览）+ 本章备注（最多 20 条） | `BuildCurrentChapterReferenceText()` |
| F12 | 同 F1（老入口保留） | `StoryEditorPage_KeyDown` |
| Esc / 右键 / 关闭按钮 / 点暗底 | 关掉 | 层自己的处理函数 |

- 加速器在 `RegisterReferenceOverlayShortcuts()`（MainWindow 构造里调一次）。
- 浮层是 `MainWindow.xaml` 的 `ReferenceOverlayHost`，形态照 `ChapterChoiceManagerHost`
  （满屏半透明底 + 居中卡片 + `Canvas.ZIndex` 比它高 20，免得被压在下面）。
- 文本**可选中**：这张表是给人照着按/抄命令用的。

## 有意为之的几个取舍

- **没打开章节时 F2 不空开**：给一句话告诉你先去哪儿（对应零境的"未选择角色"）。
- **说明里只写代码里确实有的东西**（写在 `BuildShortcutGuideText` 上方的注释里）——
  这张表写错比不写更坏，所以宁缺勿滥；测试里也钉了一条：
  说明写了 `Tab：清空这一位的立绘`，代码里就必须有那个处理。
- **章节参考不追求"全"**：不去解析素材名（那要连素材库一起查），只给写剧情时最常回头看的三样
  （哪几节、每节从哪句起、本章记了什么）。要加"本句引用了哪些素材"，在
  `BuildCurrentChapterReferenceText` 里续一段即可。
- **顺手收掉了旧的英文快捷键对话框**：原来 F12 弹的是一个内容写死在
  `Services/ShortcutService.cs` 里的英文对话框（全仓库唯一一份英文 UI 文案），
  现在并进参考层，那个服务连同接口一起删了。

## 想再加键时

F3/F4 在零境是"规范文本 / 当前页填写法则"。这边若要加，照同一层塞内容即可；
但**先想清楚内容从哪来**：写死的规范文本好办，页相关的最好按"当前在哪一页"分支
（F1 就是这么做的），别在层里堆 if。
